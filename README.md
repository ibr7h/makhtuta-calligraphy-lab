# مخطوطة — Makhtuta Calligraphy Lab

معمل ويب تعليمي للخط العربي يعتمد بنية هجينة:

- **SVG** لخطوط التسطير والنموذج الإرشادي.
- **Canvas 2D** للحبر والقصبة الحرة.
- **Stroke Data Model** لحفظ الضربات وإعادة رسمها وتشغيلها.
- **Pointer Events** لدعم الماوس واللمس والقلم الإلكتروني والضغط والميل.

## الإصدار الحالي

Hybrid V5 — Brush Settings

يتضمن لوحة إعدادات للقصبة مستوحاة من مفهوم Brush Settings في برامج الرسم الاحترافية، ومكيّفة للخط العربي:

- حجم القصبة.
- زاوية القطّة.
- استدارة السن.
- تباعد أخذ العينات.
- التنعيم.
- شفافية الحبر.
- حساسية الضغط والحد الأدنى للسماكة.
- منحنى الضغط: ناعم / خطي / قوي.
- زاوية ثابتة أو Twist من القلم الإلكتروني.
- Presets: نسخ، رقعة، ثلث، كوفي، قلم ناعم.
- Preset شخصي محفوظ محليًا.

## التشغيل

افتح `index.html` مباشرة، أو فعّل GitHub Pages على الفرع `main` والمجلد الجذر `/`.

## مبدأ هندسي مهم

Canvas ليس مصدر الحقيقة. كل ضربة تحفظ كبيانات مستقلة بإحداثيات نسبية وخصائص القلم؛ ثم يعاد تصييرها على Canvas. هذا يحافظ على الرسم عند تغيير الحجم أو تدوير الشاشة ويمهد للتحليل والتقييم لاحقًا.

## خارطة الطريق

1. فصل Brush Engine في ملف مستقل.
2. تصدير SVG/PDF عالي الدقة.
3. تحليل زمن الكتابة والسرعة والضغط والوقفات.
4. مقارنة مسار الطالب بالنموذج الإرشادي.
5. Preset Manager متعدد مع استيراد/تصدير JSON.
6. PWA وOffline assets.
